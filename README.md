# CobaltAI Transformation (Test Project Scaffold)

Starter repository for two review-response automation scenarios:

- Scenario 1: Google My Business via Make.com webhook/polling
- Scenario 2: Sourcr via browser automation (Playwright) with secure credential login

This repo is scaffolded to support the shared Claude-driven routing logic and to demonstrate robust error handling (no silent failures).

## Local setup

Requires Node.js (LTS recommended).

1. Install dependencies
2. Create a `.env` file (if you choose to run locally) with non-production keys for Claude and/or Playwright
3. Run tests

Note: credentials are not committed. Use environment variables in all integrations.
